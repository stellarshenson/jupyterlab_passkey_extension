    **Result**: The vault is the one part of the extension that encrypts. `vault/store.py` keeps one JSON file: a random 32-byte data key seals all entries (names included) as one AES-256-GCM blob, and each slot wraps that key - `Scrypt` (n=2^17) of the recovery passphrase, or `HKDF` of a passkey's PRF - with every slot parameter bound as associated data, so a changed salt or hostname fails to open rather than opening wrongly; writes are locked, temp-file, fsync, rename. **Why slots**: adding or removing a passkey never re-encrypts entries.
